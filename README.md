# Dominican Valle Restaurant Website

A single-page, mobile-friendly website for **Dominican Valle Restaurant**, a Dominican restaurant in Washington Heights, New York.

## Features

- **Bilingual sections** (English / Spanish): Menu / Nuestro Menú, About Us / Nosotros, Hours / Horario, Visit Us / Visítanos
- **Full menu** section
- **Customer reviews** section
- **Order online** links to DoorDash, Grubhub, and Uber Eats
- **Embedded Google Map** and tap-to-call phone link
- **Instagram** link
- **Responsive layout** that adapts to phones, tablets, and desktops

## Tech Stack

| Part | Technology |
|---|---|
| Structure | HTML |
| Styling | CSS (media queries for mobile) |
| Fonts | Google Fonts (Playfair Display, DM Sans) |

No frameworks or build tools. The whole site is one `index.html` file.

## Run It Locally

```bash
git clone https://github.com/JFCC99/dominican-valle.git
cd dominican-valle
```

Then open `index.html` in any web browser.
